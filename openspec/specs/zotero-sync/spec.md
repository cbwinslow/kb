# zotero-sync Specification

## Purpose
Enables synchronization of local Zotero reference libraries, collections, PDF attachments, and Better BibTeX citation keys.

## Requirements

### Requirement: Local Zotero Library Discovery and Reading
The system SHALL detect local Zotero SQLite database instances and read reference metadata, collections, and linked PDF file paths.

#### Scenario: Discovering local Zotero database
- **WHEN** user initiates Zotero synchronization
- **THEN** system locates the local Zotero storage directory, parses the SQLite schema in read-only mode, and identifies newly added items

### Requirement: Better BibTeX Citation Key Synchronization
The system SHALL import persistent citation keys generated by Better BibTeX for canonical citation referencing.

#### Scenario: Syncing citekeys into database records
- **WHEN** reference items are synchronized from Zotero
- **THEN** system stores the canonical Better BibTeX citekey (e.g., `albert2024analyzing`) on the corresponding document record

### Requirement: Automated Zotero Library Monitoring and Auto-Ingestion
The system SHALL monitor the local Zotero SQLite library for changes and automatically execute the ingestion pipeline for newly detected paper attachments.

#### Scenario: Detecting library modifications via watcher
- **WHEN** the Zotero database modification timestamp updates or polling interval elapses
- **THEN** system identifies reference items added or modified since the last recorded synchronization cursor

#### Scenario: Auto-ingesting newly attached PDF
- **WHEN** an unindexed reference item with a valid PDF file attachment is discovered
- **THEN** system automatically executes document parsing, formula extraction, table extraction, and database persistence
